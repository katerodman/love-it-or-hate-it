# Love It or Hate It

A phone-friendly game for rating 30 animal-advocacy organizations on their name, logo and work (1 = hate it, 5 = love it).

When a player finishes, their answers are saved to a Google Sheet and emailed by a small Google Apps Script (`google-sheet/Code.gs`). Progress is kept in the player's own browser so they can leave and come back.

Static site: `index.html` plus `logos/`. Hosted with GitHub Pages.
